# Interfaz híbrida adaptativa a la intención

Fecha: 2026-10-14. Estado: acuerdo de diseño para evolución futura.

La interfaz dejará de ser exclusivamente conversacional y pasará a ser adaptativa a la intención:

- Lenguaje natural para expresar qué queremos hacer.
- Tarjetas convencionales para completar, revisar o corregir datos.
- Ejecución directa cuando la instrucción ya contiene toda la información necesaria.
- Conversación únicamente cuando aporte valor o resuelva una ambigüedad.

Principio: la intención determina qué interfaz aparece; la tarea determina cómo interactuamos con ella. El chat es una opción, no una obligación.

Ejemplo: una instrucción de crear pedido para un cliente con un producto específico puede producir una tarjeta precargada; solo se preguntan datos faltantes o ambiguos.

Este acuerdo no implica implementación ni despliegue inmediato. Se evaluará en un próximo ciclo de IBUI.
