# Interaction model — draft

1. **Idle:** nearly blank canvas with a central intent field.
2. **Guidance:** discreet examples and a fallback way to explore for first-time users.
3. **Interpretation:** determine likely action, context, and missing inputs; clarify uncertainty.
4. **Progressive UI:** reveal only the controls and information required.
5. **Confirmation:** summarize potentially consequential actions before committing.
6. **Result:** show success, recoverable errors, or a clear next step.

## Pilot intents

- Taller: `Crear pedido para Marvin`.
- Tienda: `Buscar cirio pascual`.

Text is the initial interaction modality. Voice is a future-compatible modality, not a prerequisite for the prototype. Available actions vary by role and permission.
