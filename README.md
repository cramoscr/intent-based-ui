# Intent-Based-UI (IBUI)

**Experimental, open-source, intent-first user interface concept.**

What if an application began with a nearly blank screen and one simple question: **What do you want to do?**

IBUI explores progressive interfaces that respond to user intent expressed through **text, voice, or visual controls**. The goal is less navigation, less friction, and just enough interface for the task at hand.

## First pilot

[Cirios-App](https://github.com/cramoscr/cirios-app), an artisan workshop and store, is the first testbed. The initial journeys are **create an order** (Taller) and **find a product** (Tienda). [Fabrícamelo](https://github.com/cramoscr/fabricamelo) is a related project.

**Current status:** exploration. No generic framework or production integration is claimed.
