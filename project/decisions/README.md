# Decision log

## DEC-001 — Independent project and repository

**Status:** Accepted.

IBUI has its own public repository (`cramoscr/intent-based-ui`) under Apache License 2.0. Its vision, project control, specifications and prospective reusable software live here. Fabrícamelo and Cirios-App are related projects, not owners of IBUI.

## DEC-002 — Intent-first, not voice-only

**Status:** Accepted as product direction, subject to usability validation.

The starting point is user intent, expressed via text, voice, or visual controls. Interface elements emerge progressively. This is not a decision to implement an AI framework.

## DEC-003 — Isolated pilot

**Status:** Accepted.

Cirios-App is the first real-world testbed. Prototype work should be isolated from FAB-011 and production. A branch name `experiment/intent-based-ui` is proposed, not yet created or verified.
